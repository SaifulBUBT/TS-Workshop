# TS-Workshop

This repository is a simple TypeScript project setup with local TypeScript, VS Code settings, and build/dev scripts.

## Project Structure

```text
TS-Workshop/
├─ .vscode/
│  └─ settings.json
├─ dist/          # Compiled JavaScript output
├─ node_modules/
├─ src/
│  └─ index.ts
├─ package.json
├─ package-lock.json
├─ tsconfig.json
└─ README.md
```

## Required packages

Install the required development dependencies:

```bash
npm init -y
npm install --save-dev typescript @types/node ts-node ts-node-dev tsconfig-paths tsc-alias
```

## package.json scripts

```json
{
  "scripts": {
    "build": "tsc && tsc-alias",
    "start": "node dist/index.js",
    "dev": "ts-node-dev --respawn -r tsconfig-paths/register src/index.ts"
  }
}
```

- `npm run dev`: Run the project in development mode with live reload.
- `npm run build`: Compile TypeScript to `dist/` and rewrite path aliases.
- `npm start`: Run the compiled output from `dist/`.

## tsconfig.json

The `tsconfig.json` file configures TypeScript compilation for this project.

Key settings:

{
"compilerOptions": {
"target": "ESNext",
"module": "NodeNext",
"moduleResolution": "NodeNext",
"rootDir": "./src",
"outDir": "./dist",
"paths": {
"_": ["./.src/_"]
},
"strict": true,
"noImplicitAny": true,
"strictNullChecks": true,
"esModuleInterop": true,
"allowSyntheticDefaultImports": true,
"resolveJsonModule": true,
"sourceMap": true,
"declaration": true,
"declarationMap": true,
"skipLibCheck": true,
"forceConsistentCasingInFileNames": true,
"types": ["node"]
},
"include": ["src/**/*"],
"exclude": ["node_modules"]
}

## VS Code settings

Create `.vscode/settings.json` with:

```json
{
  "typescript.tsdk": "node_modules/typescript/lib",
  "typescript.validate.enable": true
}
```

This ensures VS Code uses the workspace TypeScript installation and shows TypeScript diagnostics in the editor.

## How to use

1. Install dependencies:

```bash
npm install
```

2. Run development mode:

```bash
npm run dev
```

3. Compile production files:

```bash
npm run build
```

4. Run the compiled code:

```bash
npm start
```

## Notes

- If VS Code does not show errors, use the Command Palette:
  - `TypeScript: Restart TS Server`
  - `TypeScript: Select TypeScript Version` → `Use Workspace Version`
  - `Developer: Reload Window`

- The `dist/` folder is generated by TypeScript and should not be manually edited.
